# Portfolio Website - Vihanga Liyanaarachchi

A modern, responsive portfolio website showcasing my skills, projects, and experience as a Full-Stack Developer and Mobile App Engineer.

## Features

- **Responsive Design**: Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices
- **Mobile Sidebar Navigation**: Clean hamburger menu that opens a sidebar for mobile navigation
- **Smooth Animations**: Elegant scroll animations and transitions throughout the site
- **Modern UI**: Dark theme with gradient accents and glassmorphism effects
- **Sections**:
  - Hero/Profile section with downloadable CV
  - About Me section with experience and education highlights
  - Technical Skills organized by categories
  - Projects showcase with live demos and GitHub links
  - Contact information with multiple contact methods

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Custom styling with CSS variables, flexbox, and grid
- **JavaScript**: Interactive features and smooth scrolling
- **Font**: Google Fonts (Poppins)

## Key Features Breakdown

### Desktop Navigation
- Fixed top navbar with smooth transitions
- Navigation links with hover effects
- Visible on screens wider than 1200px

### Mobile Navigation
- Hamburger icon in the top-right corner
- Sidebar slides in from the left when opened
- Dark overlay when sidebar is active
- Body scroll disabled when menu is open
- Easy navigation with smooth closing

### Performance Features

- Optimized images
- Smooth scroll behavior
- Efficient CSS transitions
- Minimal JavaScript for better performance
- Intersection Observer for scroll animations
